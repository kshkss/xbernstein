# 軸集合ごとの段階的有理 Hermite 補間

## 目的

`rational_hermite_interpolate_1d`〜`4d` を、全未知数の一括解法ではなく、軸集合ごとの小さな連立系を順に解く方式にする。

## 解法

- 頂点値と端点の分母ジェット（重み）を 1 に固定する。
- 非空の軸集合を、要素数の昇順・同じ要素数では辞書順に処理する。
  - 2D: `x`, `y`, `xy`
  - 3D: `x`, `y`, `z`, `xy`, `xz`, `yz`, `xyz`
  - 4D: 全ての非空軸部分集合
- 軸集合 `S` ごとに `alpha = 1_S` と `alpha = 2_S` の補間条件、および同じ支持を持つ分子・分母 endpoint-jet の未知数だけを抽出する。
- 前段の解を右辺へ反映し、各小系をスケーリング済み最小ノルム最小二乗で解く。
- 全段階の後、元の全条件に対する残差と分母 Bernstein 重みの正値性を検証する。
- `xxy` などの中間次数の微分は、対応する高次条件の積の微分則に現れる既知入力として使う。

## 受け入れ条件

- 既知の有理三次関数を 1D〜4D で復元できる。
- 同じ交差数でも異なる軸集合（例: `xy` と `xz`）の行・未知数列が重ならない。
- 端点微分の再現、バッチ、JIT、自動微分、正値重み検証を既存仕様どおり維持する。
- 特異な小系は最小ノルム解を使い、不整合な小系はエラーにする。
